# 脚本说明

`scripts/` 放构建期与维护期用的脚本，**不参与客户端打包**。

## 现有脚本

| 脚本 | 用途 | 命令 |
|---|---|---|
| `validate-data.js` | 校验 `data/builds.json`（必填 / 类型 / 取值 / id 重复） | `node scripts/validate-data.js` |
| `check-links.js` | 检查所有 `.md` 里的相对链接是否失效 | `node scripts/check-links.js` |
| `make-icons.ps1` | 从原始 key art 裁圆形图标（气泡 / 托盘用） | `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\make-icons.ps1` |

CI 会跑前两个（见 `.github/workflows/validate.yml`）。

## 用法示例

```bash
# 校验数据
node scripts/validate-data.js
# ✓ data/builds.json
#   版本 1.0 · 游戏 1.0.1.3 · 2 个流派

# 校验指定文件
node scripts/validate-data.js data/builds.json

# 文档内链检查（改完文档、重命名后必跑）
node scripts/check-links.js
# ✓ 文档内链全部有效（16 个文档，48 个链接）
```

`make-icons.ps1` 需要在 **Windows PowerShell 5.1** 下跑（PowerShell 7 的 `System.Drawing`
程序集转发会导致 `Add-Type` 编译失败），裁切坐标写在脚本的 `$presets` 里。
