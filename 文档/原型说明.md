# 原型说明

单文件可交互原型，**双击 `index.html` 用浏览器打开即可**，无需安装、无需构建。

## 用途

这个原型不是视觉稿，是**可点的交互验证**：

- 验证信息密度：一屏能放几条流派、卡片上放多少信息不挤
- 验证键盘路径：全程不碰鼠标能不能走完"找流派 → 看详情"
- 验证区块顺序：详情页 8 个区块从上到下的阅读节奏
- 给开发者当实现参照：DOM 结构和数据字段一一对应

## 键盘操作

| 键 | 作用 |
|---|---|
| `Alt + \`` / `` ` `` | 呼出 / 收起面板（浏览器里只能用反引号） |
| `↑ ↓` | 在流派列表中移动 |
| `Enter` / `→` | 展开卡片（玩法技巧 + 核心宝藏） |
| `←` | 收起卡片 / 详情页返回列表 |
| `D` | 打开 / 关闭流派详情页 |
| `F` / 点击搜索栏 | 打开筛选下拉（武器 / 刻印 / 标签 + 排序） |
| `I` | 投稿入口（v1 只有提示） |
| `H` | 使用帮助 |
| `Esc` | 逐级退出 |

鼠标：点卡片展开、点 `详情` 进详情页、点右上 `☆` 打分、`♡` 收藏。

## 数据说明

- `复仇战士剑盾流` = **真实社区数据**（来源：抖音图文《失落城堡2流派》第7集）
- 其余流派为示例数据，用于验证不同数据量下的排版
- 图标来自[失落城堡2中文维基](https://lc2.huijiwiki.com/)（CC BY-NC-SA 4.0），加载失败会自动降级为「稀有度底色 + 名称首字」色块

## 已知限制

- 浏览器里没有真实的全局热键、透明窗口、置顶 —— 这些只在正式客户端才有
- 打分/收藏只存内存，刷新即丢
- 筛选与搜索是前端即时过滤，数据量大时需要索引

## 与正式客户端的关系

正式客户端（Electron）会**复用这套 DOM 结构与样式**，只把：
- 数据源从内联 JS 换成 `data/builds.json`
- 窗口从浏览器换成透明置顶的 BrowserWindow
- 键盘从 `document.keydown` 换成 `globalShortcut`

也就是说：**原型定稿 = 前端可以直接开工**。

## 动效

原型与真机使用**同一套动效层**：

- 点击气泡 → 面板上浮淡入、卡片逐张入场
- 点「详情」→ 详情页右滑进入；`← 返回` / `Esc` → 列表左滑回来
- 展开卡片 → 新增区块淡入上移
- 打开筛选 / 帮助 → 面板缩放入场
- 收藏 ♡、打分 ☆ → 轻微弹跳
- 确认筛选 → 列表重新入场

> 原型里没有窗口级淡入（浏览器里没有独立窗口），真机上会多一层窗口淡入。
> 若系统开启「减少动态效果」，原型也会自动关闭动画。

## 视觉皮肤

原型与正式客户端共用同一套「失落城堡2 风格」皮肤：虚空紫渐变底 + 妮娜封印场景暗纹、
金色细线与四角金饰、金属渐变标题；卡片/按钮/弹层都是紫罗兰玻璃质感。
CSS 源在 `apps/desktop/src/renderer/index.html` 的皮肤段落，原型同步。
