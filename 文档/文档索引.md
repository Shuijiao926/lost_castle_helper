## 文档约定

- 文档随设计变更**同步更新**，不留在 PR 里当历史
- 涉及取舍的结论写进[方案总纲](./方案总纲.md)的「决策记录」，不只写在 PR 描述里
- 路径、字段名以代码为准，**文档过期视为 bug**
- 新增文档请放进本目录，并在本索引登记

## 子目录 README

`apps/`、`data/`、`scripts/` 下各有一个简短的 `README.md`，**只是指路页**（方便在 GitHub 点进目录时能看到说明），
完整内容以本目录下的文档为准。
