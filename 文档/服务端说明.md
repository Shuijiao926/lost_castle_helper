# 服务端说明

> 状态：**P1 完成** —— 领域骨架可运行，无数据库也能跑通「查询 / 评分 / 投稿 / 审核 / 发布」全链路。
> 设计依据见 [后端设计-DDD](./后端设计-DDD.md)。

## 启动

```bash
npm run server          # 仓库根目录
cd apps/server && npm start
cd apps/server && npm test   # 28 个用例
```

默认 `http://127.0.0.1:4317`。数据来自 `data/`，运行时数据写到 `data/runtime/`（已被 git 忽略）。

启动日志只打印**数据加载情况**，不打印接口清单：

```
INFO  [lc2] 服务已启动 url=http://127.0.0.1:4317 env=development persistence=json
INFO  [lc2] 数据加载完成 catalog={"weapons":9,"inscriptions":27,"schools":29,"treasures":0} builds={"published":2} ratings={"ratedBuilds":0} package=未发布
WARN  [lc2] 宝藏图鉴为空（P2 采集后补全）
```

## 目录结构：按大功能职责划分，模块内 DDD 分层

```
apps/server/src/
├─ index.js                    启动入口（只做装配 + 启动日志）
├─ app/                        组合根（跨模块）
│  ├─ config.js                ★ 唯一读取 process.env 的地方，所有默认值集中于此
│  ├─ container.js             依赖注入：决定用哪套仓储 / 安全组件
│  ├─ http-server.js           Fastify 装配 + 按 api/routes 注册
│  ├─ admin-auth.js            鉴权（头名与口令来自配置）
│  └─ adapters.js              hash / clock 技术适配器
├─ api/                        ★ 所有接口的公共定义（唯一的地方）
│  ├─ routes.js                路由表：方法 / 路径 / 权限 / handler 名
│  ├─ handlers.js              请求处理（薄，只做参数解析 + 调用例）
│  └─ errors.js                领域错误 → HTTP 状态码
├─ shared/                     跨模块共用
│  ├─ logger.js                ★ 统一日志组件（分级别、带 scope、可 child）
│  ├─ kernel/errors.js         领域错误（含 RateLimitedError / BadRequestError）
│  ├─ kernel/event-bus.js      进程内领域事件
│  ├─ kernel/shared-kernel.js  加载前后端共用校验（@lc2/shared）
│  └─ infrastructure/json-database.js
└─ modules/                    ★ 每个目录 = 一个限界上下文
   ├─ catalog/                 图鉴：武器 / 刻印 / 宝藏 / 流派分类
   ├─ builds/                  流派聚合根 + 不变量
   ├─ submissions/             投稿与审核
   ├─ ratings/                 评分
   ├─ publishing/              数据包版本与 hash
   └─ security/                安全管控：请求指纹 + 滑动窗口限流
      └─ 每个模块内：domain/ · application/ · infrastructure/
```

**纪律**：

- 路由只在 `api/routes.js` 声明；模块里不再出现 HTTP 相关代码
- 环境变量只在 `app/config.js` 读取；业务代码不碰 `process.env`
- 日志只用 `shared/logger.js`；业务代码不直接 `console.log`
- 跨模块只能通过 application 用例或仓储接口，不 import 对方 domain 内部实现
- `domain/` 禁止出现 `fastify` / `@prisma/client` / `fs` / `crypto`

## 接口（声明于 `src/api/routes.js`）

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/health` | 公开 | 健康检查（持久化模式） |
| GET | `/api/catalog` | 公开 | 武器 9 / 刻印 27 / 流派分类 29 |
| GET | `/api/builds` | 公开 | 卡片列表（`weaponType` `inscriptionId` `sort` `limit` `offset`） |
| GET | `/api/builds/:id` | 公开 | 详情（已剥离内部字段） |
| POST | `/api/ratings` | 公开 | `{ buildId, score }`，0–10，**有限流** |
| POST | `/api/submissions` | 公开 | `{ payload, meta }`，必须勾选授权，**有限流** |
| GET | `/api/submissions` | 管理员 | 待审队列 |
| POST | `/api/submissions/:id/approve` | 管理员 | 通过 → 写回流派 |
| POST | `/api/submissions/:id/reject` | 管理员 | 驳回（必须填原因） |
| GET | `/api/packages/latest` | 公开 | 最新数据包版本 |
| POST | `/api/packages/publish` | 管理员 | 生成新数据包（sha256 + 版本递增） |

管理员鉴权：请求头名 `x-admin-token`（`API_ADMIN_HEADER` 可改），值来自 `ADMIN_TOKEN`。

## 安全管控模块（`modules/security`）

| 层 | 内容 |
|---|---|
| domain | `evaluateWindow()` 纯函数（滑动窗口）、`RateLimitPolicy` 值对象 |
| application | `RateLimiter.assert(action, key)`，超限抛 `RateLimitedError` |
| infrastructure | 请求指纹（`sha256(ip\|ua)[:32]`，不存明文）、限流计数持久化 |

**设计要点**：

1. **指纹不存明文**：只存 `sha256(ip + '|' + ua)[:32]`，换 IP 或 UA 即视为新指纹
2. **计数落盘**：写 `data/runtime/security-limits.json`，重启不能绕过限流
3. **先校验后限流**：非法请求（如分数越界）不消耗配额，避免误伤
4. **策略可配**：`RATING_RATE_LIMIT` / `SUBMISSION_RATE_LIMIT` 等环境变量控制

默认策略：

| 动作 | 默认限制 | 说明 |
|---|---|---|
| `rating` | 20 次 / 分钟 | 同指纹同窗口 |
| `submission` | 5 次 / 10 分钟 | 人工审核成本高，门槛更高 |

## 已实现的领域规则

| 规则 | 位置 |
|---|---|
| 字段级校验（与客户端同一份 `@lc2/shared`） | `modules/builds/domain/build.js` |
| 图鉴引用校验（武器类型、刻印归属） | 同上（严格拒绝 / 宽松降级警告） |
| 宝藏顺序不可重复 | 同上 |
| **内部字段（宝藏深度 `t`）绝不外泄** | `stripInternal()`，单测覆盖 |
| 投稿必须勾选授权 | `modules/submissions/domain/submission.js` |
| 只有 `PENDING` 能被审核 | 同上 |
| 评分同指纹只保留最后一次 | `modules/ratings/domain/rating.js` |
| 限流（评分 / 投稿） | `modules/security/` |
| 数据包版本递增 + 稳定序列化（同内容同 hash） | `modules/publishing/domain/package.js` |
| 单条脏数据不拖垮列表 | `modules/builds/application/use-cases.js`（返回 `skipped`） |

## 配置（`app/config.js`）

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `PORT` / `HOST` | 4317 / 127.0.0.1 | 监听地址 |
| `LOG_LEVEL` | info | debug / info / warn / error |
| `DATA_DIR` / `RUNTIME_DIR` | `<repo>/data` 与其下 `runtime` | 种子数据 / 运行时数据 |
| `API_PREFIX` | `/api` | 接口前缀 |
| `API_ADMIN_HEADER` | `x-admin-token` | 管理员请求头名 |
| `ADMIN_TOKEN` | `change_me` | 管理员口令（上线必须改） |
| `RATING_RATE_LIMIT` / `RATING_RATE_WINDOW_MS` | 20 / 60000 | 评分限流 |
| `SUBMISSION_RATE_LIMIT` / `SUBMISSION_RATE_WINDOW_MS` | 5 / 600000 | 投稿限流 |
| `CORS_ORIGINS` | 空（允许所有） | 生产建议填白名单 |
| `MAX_BODY_BYTES` / `MAX_UPLOAD_BYTES` | 1MB / 8MB | 请求体 / 上传上限 |
| `FILE_BASE_URL` | 空 | 数据包对外地址前缀 |
| `DATABASE_URL` | 空 | P4 启用 PostgreSQL |

## 终端乱码（Windows）

控制台默认 936(GBK)、Node 输出 UTF-8，中文日志会乱码。
`npm run start` / `npm run dev` 已内置 `chcp 65001`；若直接 `node src/index.js`，请先执行：

```powershell
chcp 65001
```
