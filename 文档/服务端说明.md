# @lc2/server — 后台服务（骨架）

> **当前未启用。** 数据与文件暂由 GitHub 承担，详见 [./后台架构.md](./后台架构.md)。

Node + Fastify + Prisma + PostgreSQL。**没配数据库也能启动**——业务层会自动降级为 JSON 文件存储。

## 启动

```bash
cd apps/server
cp .env.example .env      # 可选
npm install
npm start                 # 无 DATABASE_URL → JSON 文件模式
curl http://127.0.0.1:4317/api/health
```

接数据库：

```bash
# .env 填 DATABASE_URL=postgresql://user:pass@host:5432/lc2
npx prisma db push
npm start
```

## 结构

```
prisma/schema.prisma     6 张表：Build / BuildVersion / Rating / Submission / DataPackage / Admin
src/
├─ index.js              启动入口（依赖缺失时友好提示）
├─ app.js                Fastify 装配 + 全部路由
├─ config.js             唯一读 process.env 的地方
├─ plugins/
│  ├─ db.js              Prisma 连接（无 DATABASE_URL 返回 null → 降级）
│  └─ files.js           文件存储：github | local（换 OSS 只改这里）
├─ modules/
│  ├─ builds.js          流派列表 / 详情
│  ├─ ratings.js         评分（同指纹覆盖，防刷）
│  ├─ submissions.js     投稿：创建 / 待审 / 通过 / 驳回
│  └─ packages.js        数据包版本与发布
└─ store/json-store.js   无数据库时的文件存储
```

## 接口

```
GET  /api/health
GET  /api/builds              流派列表（含评分汇总）
GET  /api/builds/:id
POST /api/ratings             { buildId, score }        公开
POST /api/submissions         { build, meta }           公开
GET  /api/submissions         待审队列                  管理员
POST /api/submissions/:id/approve | reject              管理员
GET  /api/packages/latest     数据包版本
POST /api/packages/publish    发布数据包                管理员
```

管理员暂时用请求头 `x-admin-token`（值来自 `.env` 的 `ADMIN_TOKEN`）。
