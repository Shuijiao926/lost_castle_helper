## 2. 详情页分区（9 个区块，对齐玩家实际关注顺序）

对照真实社区流派图文（抖音「失落城堡2流派」7 图）核对后，按玩家关注度排序：

| # | 区块 | 内容 | 数据字段 | 图标 |
|---|---|---|---|---|
| ① | 头部 | 刻印大图标 + 流派名 + 武器·刻印 + **特点标签** + **伤害参考** + 评分 + 打分投票 + 别名 | `name/aliases/features/dmgLabel/dmg/rating/votes` | ✅ |
| ② | 玩法技巧 | 一句话核心思路 | `tip` | — |
| ③ | **武器刻印** | 刻印效果原文 + **共鸣选择（如 2-1-2）** 与各节点收益 | `inscEff / resonance{code,nodes}` | ✅ |
| ④ | **灵魂石** | 词条表（名称 + Lv 上限 + 效果）+ 石头分配方案（增伤/回复/资源/攻频） | `soulStones[] / soulPlan[]` | — |
| ⑤ | **毕业装备 + 过渡** | 毕业武器/衣服（面板/属性/获取方式）+ **过渡装怎么拿** | `gear{weapon,armor,obtain} / transition[]` | ✅ |
| ⑥ | **宝藏选择** | 混沌宝藏 / 合成金宝藏 / 其他宝藏 + 取舍说明 | `treasures{chaos,gold,other} / treasureNotes[]` | ✅ |
| ⑦ | **诅咒宝藏** | 每件效果 + **净化 / 不净化** 判断 | `cursed[{name,eff,verdict}]` | ✅ |
| ⑧ | **炼金与猎人道具** | 炼金材料 + 猎人道具（飞盘→香蕉） | `alchemy[] / hunterItems[]` | ✅ |
| ⑨ | **梦魇推荐加点** | 逐条词条 + 百分比 | `nightmareList[{n,p}]` | — |
| ★ | **宝藏门槛顺序**（本工具独有） | 根级铺垫 → 1级核心 → 2级上限，可勾选已拿、算进度 | `treasureOrder[]` | ✅ |

外加：标签 `tags[]`、来源与版本 `src/updatedAt/gameVersion`。连招要点 `combos[]` 已合并进「玩法技巧」区块。

> ★ 项是攻略图文里**没有**的——作者只给"拿什么"，不给"什么顺序"。我们复刻游戏掉落机制算出门槛顺序，这是差异点。
> ⑤⑦⑧ 是看了真实图文才补上的：**纯文字攻略会漏掉具体装备名、诅咒宝藏的净化判断、炼金材料**，而这些恰恰是玩家最想抄的。

## 3. 图标方案

| 环节 | 方案 |
|---|---|
| 来源 | [失落城堡2中文维基](https://lc2.huijiwiki.com/)（CC BY-NC-SA 4.0），已收录武器类型 9 个、刻印 27 个的图标 URL |
| 原型 | 直接引用 wiki CDN 的缩略图；**加载失败自动降级为首字色块**（不会出现裂图） |
| 正式版 | 图标下载后打包进安装包（离线可用、不依赖 wiki 带宽），README 注明来源与许可 |
| 兜底 | 任何图标缺失 → 用稀有度对应底色 + 名称首字的圆形色块 |
| 版权 | 只用于非商业开源工具，标注来源与 CC BY-NC-SA；游戏美术原始权利归 Hunter Studio |

> 已知可直接拿到图标的宝藏：刺客面罩、游侠羽饰、剑士腕甲、兽骨护指、雷龙翼膜、集电瓶、强磁手套、火焰风衣等。其余待批量抓取（`scripts/fetch_wiki.py` 顺便抓图标 URL 写进 `treasures.json`）。

## 4. 数据字段（v0.6 基础上无破坏性变更）

新增/确认：

```jsonc
"rating": 7.6,      // 社区平均分（10 分制）
"votes": 1299,      // 打分人数
"myVote": 4,        // 本机用户打的分（仅本地存储，不参与汇总）
"icons": {          // 图标引用（可由抓取脚本自动填）
  "inscription": "…",
  "treasures": { "刺客面罩": "…" }
}
```

`rating` / `votes` 由社区打分累计，决定「全部」页按热度排、「排行榜」页按分排。

## 5. 键盘操作

| 键 | 作用 |
|---|---|
| `↑ ↓` | 选卡片 / 详情页滚动 |
| `Enter` / `→` | 展开卡片 |

| `Esc` | 逐级退出（详情 → 列表 → 清搜索/筛选 → 收起面板） |
